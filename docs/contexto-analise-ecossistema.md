## O que provavelmente **corrigir** no site (hipótese até ler o PDF)

1. **Nomenclatura** — alinhar um termo só (moduladores biofísicos × biomoduladores), conforme o PDF oficial.  
2. **Textos institucionais** — fundadores, método, ferramentas e passos: conferir palavra a palavra com o PDF.  
3. **Depoimentos** — se o PDF trouxer as falas completas, restaurar as versões longas (hoje estão cortadas).  
4. **Mapa Holográfico / Fitoalquimia** — se o PDF tiver a definição oficial, enriquecer as seções sem virar “card spam”.

## O que provavelmente **aproveitar** do PDF (sem planos)

1. Bloco/conceito **Ecossistema de Amor em Movimento** (nome do próprio PDF) — uma seção ou parágrafo de propósito, não dashboard.  
2. Linguagem de “amor em movimento” / integração dos quatro corpos, se estiver mais clara no PDF.  
3. Explicações oficiais de **fitoalquimia** e **mapas holográficos**.  
4. Qualquer lista de pilares do ecossistema que **não** seja preço de assinatura.

## O que **não** fazer

- Não criar planos mensais, trimestrais, assinaturas ou “clubes” de cobrança recorrente.  
- Não copiar preços/planos do PDF para o site sem validação do dono.  
- Não apagar a loja (carrinho / Mercado Pago) em nome do PDF institucional.  
- Não alterar marca já consolidada (WhatsApp, endereço, YouTube, domínio) sem pedido explícito.
