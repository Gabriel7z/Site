# Álbum completo (não publicar no GitHub Pages)

Os MP3 desta pasta só saem pelo download autenticado da API, depois do pagamento **aprovado**.

O produto é o álbum **Déclic — Liberte sua Expressão**, 8 faixas, um ZIP só.

Troque `01-faixa-1.mp3` … `08-faixa-8.mp3` pelas masters oficiais (mesmos nomes de arquivo) e rode:

```bash
bash scripts/make-album-previews.sh
```

Isso gera as prévias curtas em `assets/audio/album/preview-1.mp3` … `preview-8.mp3`. Não coloque as faixas completas em `assets/`.
