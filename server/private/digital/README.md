# Álbum completo (não publicar no GitHub Pages)

Os MP3 desta pasta só saem pelo download autenticado da API, depois do pagamento **aprovado**.

Troque os arquivos de `musicas-neuroconectivas/` pelas faixas oficiais da Família CEME (mesmos nomes) e rode:

```bash
bash scripts/make-album-previews.sh
```

Isso gera as prévias curtas em `assets/audio/album/preview-1.mp3` etc. Não coloque as faixas completas em `assets/`.
